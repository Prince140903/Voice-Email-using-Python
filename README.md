# Voice Email using Python

## Overview

The **Voice Email** project allows users to send emails using voice commands. It utilizes Python libraries for speech recognition and email sending, making it a convenient tool for hands-free communication.

## Features

- Convert voice input into text.
- Send emails using SMTP protocol.
- User-friendly interface.
- Customizable email settings.

## Requirements

- Python 3.x
- Required Python libraries:
  - `speech_recognition`
  - `smtplib`
  - `pyaudio` (for microphone input)
 
You can install the required libraries using pip.
